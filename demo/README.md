# 留白 · TXT 閱讀器 Demo

無後端、無建置依賴的 HTML / CSS / JavaScript 原型。直接用瀏覽器開啟 `dist/index.html` 即可使用。

## 操作流程

- 首頁點「開啟 TXT 檔案」，在對話框選擇示範文字，或直接點首頁的示範文章。
- 閱讀頁上下捲動；「更換文字檔」可切換另一篇文章，從頂端重新閱讀。
- 對話框的「試試其他狀態」可模擬空白檔案及讀取失敗；取消或失敗不會替換目前內容。
- 也支援瀏覽器內讀取本機 UTF-8 TXT；不會上傳檔案。
- 重新整理不保留檔案或閱讀位置；沒有書架、章節、帳號或閱讀設定。

示範文章為原創模擬資料。Google Fonts 為可選字體來源，離線時使用系統襯線字體。
