# TXT 編碼說明

`.txt` 副檔名不代表 UTF-8 編碼。閱讀器第一版僅接受有效的 UTF-8；GBK、GB18030 或 Big5 檔案會顯示編碼提示，需先轉存為 UTF-8。

遇到編碼問題時，應先確認原始編碼，再嚴格解碼並以 UTF-8 寫入新的檔案，保留原檔與原始換行，避免用替代字元掩蓋資料損失。可用支援編碼選擇的文字編輯器完成轉存。

2026-10-19 檢查使用者提供的《凡人修仙传》TXT：原檔 15,224,414 bytes，嚴格 UTF-8 解碼在第一個位元組失敗；嚴格 GBK 解碼成功。已另外建立 `converted/凡人修仙传.UTF-8.txt`，並驗證重新以 UTF-8 解碼後與原文完全一致，原檔未修改。

`converted/` 只存放本機使用者轉碼副本，已加入 Git 忽略規則；書籍內容不納入版本控制。此處的轉碼不改變 MVP 僅支援 UTF-8 的產品範圍。
